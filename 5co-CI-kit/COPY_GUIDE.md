# スライド文言ガイド — 「問いへの答え」方式（正本）

> 採用: 2026-07-07（クラシエ薬品 DSP効果SIM 12枚で実証・発案者承認済み）。
> 対象: 対外提案・経営レビュー・社内報告の**すべてのCIスライド**。
> 位置づけ: `V3.2_FORMAT.md`（見た目の正）と併用する**文言の正**。丸数字禁止・単位ガイド・出典表記（Shelpha）等の既存規定はそのまま適用。

## 原則

スライドの文言は、**書き手の分類**ではなく**読者の問い**から書く。読者はページを見た瞬間に「これは自分のどの疑問に答えるページか」を知りたい。専門用語のタイトルは読者に翻訳コストを課し、説明の時間を奪う。

## ルール5箇条

### 1. タイトル＝読者の問いへの答え

見出しは「◯◯分析」「◯◯ロードマップ」のような分類名ではなく、読者が抱く疑問文を想定し、その**答え**を書く。

| Before（専門用語） | After（問いへの答え） |
|---|---|
| シナリオ比較 | うまくいった場合と、いかなかった場合 |
| 実測ベンチマーク | この予測はどこから来たか |
| 12ヵ月拡大ロードマップ | 予算はどう育てていくか |
| 推奨ターゲティング | 誰に・どこで届けるか |
| コンバージョンファネル | 投資が売上になるまでの流れ |

### 2. チャートには「図の読み方:」を1文目に

軸・色・単位・強調の意味を日常語で1〜2文。グラフを初めて見る読者を迷子にしない。
例: 「棒＝月の広告費（万円）、線＝売上に対する広告費の割合。琥珀の点線が『これ以上使うと利益を削り始める』目安ラインです。」

### 3. 判断には「なぜ」の因果を添える

数字や方針の提示だけで終えず、**読者が自分の上司に説明できるレベルの因果**を1文で書く。
例: 「なぜ一律に伸ばさないのか——カテゴリごとに競合の強さと取れる余地が違うから。勝てる場所にお金を寄せた方が総額は大きくなる。」

### 4. 専門用語は初出で日常語を併記＋冒頭に用語ミニ辞典

- 初出時: 「TACoS（売上に対する広告費の割合）」のように括弧で言い換え
- デッキ冒頭に「この資料の読み方」1枚（約束事3つ＋用語辞典6〜8語）を置くと、以降の全ページが軽くなる

### 5. 誠実トーンの定型

信頼は言い回しで作る。推奨パターン:
- 「良く見せるための数字ではなく、**守れる数字**です」（保守前提の説明）
- 「**上振れも下振れも、先にお見せします**」（感度分析の導入）
- 「まず使ってくださいではなく、**確かめながら増やす**」（予算提案）
- 「この図に乗っていない価値」（控えめ試算の上振れ余地の示し方）

## 検収チェック（はみ出しゲート通過後）

**タイトルだけを縦に読んで、資料の主張が通るか**を最終チェックする（タイトル＝答えなら、目次が要旨になる）。

## 実証結果（採用根拠）

クラシエ薬品 DSP効果SIM（12枚）で全面適用し、発案者から「専門用語ではなく、問いからの〜という文言の修正方針、とても良い」と明示的な評価。前提知識のない出席者を想定した商談資料で、説明時間を消費せずページの主張が伝わる構成を実現した。
