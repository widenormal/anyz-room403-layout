# SLIDE-PATTERN-butterfly-comparison-chart

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** butterfly-comparison-chart
**概要：** 中央にカテゴリラベル列を置き、左右に2グループ（自社/競合、男性/女性、前期/当期 等）の横棒を鏡映しに伸ばすバタフライ（対向棒）チャート。上部に左右グループ名ヘッダ、棒端に値ラベルを付け、項目ごとの2者対比を一覧で示す。
**適したシーン：** 自社と競合の項目別比較、2部門・2製品の性能対比、施策前後のスコア比較、人口ピラミッド型のセグメント比較

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| グループ名ヘッダ | 左右がどのグループかをスウォッチ付きで明示 | 各2〜6文字 |
| 中央カテゴリラベル列 | 比較する評価項目・属性 | 5〜6行、各4〜10文字 |
| 左向きの棒（#333333） | 主役グループ（自社等）の値。中央から左へ伸びる | 行数と同じ |
| 右向きの棒（#AAAAAA） | 比較グループ（競合等）の値。中央から右へ伸びる | 行数と同じ |
| 値ラベル（棒端） | 各棒のスコア・数値 | 整数2〜3桁 |
| X軸スケール | 左右とも中央が0、外側が最大値 | 「0 / 50 / 100」等 |
| 図の読み方 | 「左右の長さの差＝優劣」の読解ガイド | 1文40〜60文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-butterfly-comparison-chart.md を参照して、
以下の自社と競合A社の比較をバタフライチャートで示すスライドを作成してください。

【評価データ（顧客評価調査・100点満点）】
- 価格競争力: 自社 72 / 競合A社 80
- 製品品質: 自社 85 / 競合A社 78
- ブランド認知: 自社 58 / 競合A社 88
- 販売網: 自社 64 / 競合A社 75
- アフターサポート: 自社 80 / 競合A社 62
- 開発スピード: 自社 76 / 競合A社 55

【左グループ】自社
【右グループ】競合A社

【スライドタイトル】
品質とサポートで優位、ブランド認知が最大の劣後項目

【スケール】0〜100点
```

### 注意点
- 左右のスケール（満点・単位）は必ず同一にする。スケールが違うと鏡映し比較が成立しない
- 行は5〜6行が適切。並び順は「差が大きい順」か「重要度順」に統一し、意図を持って並べる
- 主役グループ（自社等）を左・濃グレー、比較グループを右・中間グレーに固定し、ヘッダのスウォッチと一致させる
- 値ラベルは棒の外側端（左棒は左側、右棒は右側）に置き、棒と重ねない
- バー幅は「値 ÷ 満点 × 100%」で計算する（目分量で置かない）
- 差を強調したい項目がある場合も色を変えず、タイトルまたは注記の文言で指摘する（グレースケール2色の規律を守る）
