# SLIDE-PATTERN-heatmap-matrix-table

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** heatmap-matrix-table
**概要：** 行=評価対象（施策・地域等）×列=評価軸のマトリクス表で、各セルをスコアに応じたグレー濃淡（5段階）で塗り、セル内に数値を表示するヒートマップ。濃いセルの並びで優先度・強弱が一目で分かる。
**適したシーン：** 多次元評価の一覧（施策・候補の採点表）、優先度マップ、地域×指標のパフォーマンス比較、リスク・成熟度アセスメント

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| ヘッダー行（評価軸） | 何で評価しているかを示す | 4〜5列、各3〜6文字 |
| 行ラベル（評価対象） | 評価される施策・地域等の名称 | 5行程度、各4〜10文字 |
| ヒートマップセル | スコアの濃淡＋数値 | 数値1文字（1〜5） |
| 濃淡スケール凡例バー | 濃淡と数値の対応（1=低〜5=高） | 5段階＋「低評価」「高評価」 |
| 読み方注記 | 濃い行・列が何を意味するか | 1行（20〜40文字） |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-heatmap-matrix-table.md を参照して、
以下の施策評価ヒートマップのスライドを作成してください。

【評価軸（列）】期待効果 / 実現性 / コスト効率 / 緊急度（各5段階）

【評価対象（行）とスコア】
- Web広告強化: 4, 5, 3, 5
- 会員アプリ改善: 5, 3, 4, 4
- 法人営業拡大: 4, 4, 3, 2
- 店舗リニューアル: 3, 2, 2, 3
- 海外EC展開: 5, 2, 1, 1

【スライドタイトル】
どの施策から着手すべきか — 4軸評価ヒートマップ
```

### 注意点
- 行は5行程度・列は4〜5列が適切（それ以上はセルが小さくなり数値が読めない）
- 濃淡は必ず5段階のグレー hex（#FFFFFF → #D8D8D8 → #AAAAAA → #666666 → #333333）に固定し、中間色を勝手に増やさない
- セル内の数値は必須（濃淡の印象だけで判断させない）。濃セル（スコア3以上）は白文字、薄セル（2以下）は濃文字にして可読性を確保する
- 行の並び順は「合計スコアの高い順」等の意図を持たせると読みやすい（五十音順は避ける）
- スコアの定義（何をもって5とするか）を注記か口頭で補足できるようにしておく
- 凡例バー（1〜5の濃淡スケール）は必ず付ける
