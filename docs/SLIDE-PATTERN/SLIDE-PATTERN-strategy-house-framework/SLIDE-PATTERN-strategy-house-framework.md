## Overview
**パターン名：** strategy-house-framework
**概要：** 家の形で戦略全体を1枚に統合するスライド。最上部の屋根（三角形）にビジョン、中段に戦略の柱3〜4本（各柱に柱名＋施策2個）、最下部に土台帯2層（人材・システム等の経営基盤）を配置する。
**適したシーン：** 中期経営計画の全体像、ビジョン・戦略・基盤の1枚統合、キックオフでの方針共有、部門戦略の構造化

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 屋根（三角形） | ビジョン・目指す姿 | ラベル＋1文（25文字以内） |
| 柱（3〜4本） | 戦略の柱＝重点テーマ | 柱名8〜12文字 |
| 柱内の施策 | 各柱を実現する具体施策 | 各柱2個、12文字以内 |
| 土台帯（2層） | 全戦略を支える経営基盤 | ラベル4文字＋1文（20文字以内） |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-strategy-house-framework.md を参照して、
以下の戦略をストラテジーハウスに整理したスライドを作成してください。

【ビジョン（屋根）】
2030年 地域No.1の食品物流プラットフォームになる

【戦略の柱】
1. 既存顧客の深耕：定期配送プランの拡充／顧客別収益管理の導入
2. 新規エリア開拓：隣接2県への拠点展開／地場スーパーとの提携
3. 物流DXの推進：配車計画のAI化／倉庫管理システム刷新

【土台（基盤）】
- 人材基盤：ドライバー採用強化・多能工化教育
- 経営基盤：財務規律の維持・安全管理体制の徹底

【スライドタイトル】
中期経営計画の全体像：どこへ向かい何をやるか
```

### 注意点
- 柱は3〜4本が適切（5本以上は柱幅が細くなり施策が書けない）
- 施策は各柱2個まで（3個以上入れると柱が縦に伸びて土台を圧迫する）
- 屋根のビジョンは必ず1文に絞る（家の形は「頂点＝一つの目標」を意味する）
- 土台は「どの柱にも共通で効く基盤」だけを書く（特定の柱専用の施策は柱側へ）
- 屋根＝濃・柱ヘッダ＝中・土台＝薄のグレー階調で上下の階層感を出す
