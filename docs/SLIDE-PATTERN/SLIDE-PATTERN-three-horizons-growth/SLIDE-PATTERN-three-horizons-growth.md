## Overview
**パターン名：** three-horizons-growth
**概要：** McKinseyのスリーホライズン。左下から右上へ重なって伸びる3本のS字曲線（H1：中核事業＝濃、H2：成長事業＝中、H3：将来の種＝薄）で、X軸＝時間（現在〜3年〜5年以降）・Y軸＝価値の成長軌道を描く。各曲線には事業例つきの説明ラベルボックスを添える。
**適したシーン：** 成長投資の時間軸ポートフォリオ、中長期の事業開発ロードマップ、新規事業と既存事業の位置づけ整理、R&D投資配分の議論

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-three-horizons-growth.md を参照して、
以下の事業ポートフォリオをスリーホライズンで整理したスライドを作成してください。

【H1 中核事業（現在の収益源）】
既存SaaSの拡販・保守 — 守りながら利益率を高める

【H2 成長事業（1〜3年で立ち上げ）】
海外展開・隣接業種向け新製品 — 次の収益の柱に育てる

【H3 将来の種（3〜5年以降）】
AIエージェント事業のリサーチ — 小さく試して選択肢を持つ

【スライドタイトル】
成長投資の時間軸：いま・つぎ・その先に何を仕込むか
```

### 注意点
- 曲線は必ず3本・グレー濃度は H1=濃 → H2=中 → H3=薄 で固定（時間の遠さ＝薄さ）
- 曲線の立ち上がり位置をずらすこと（3本が同時に立ち上がるとホライズンの意味がない）
- ラベルボックスは曲線と重ならない位置（チャート上部）に置き、破線リーダーで対応づける
- 各ホライズンの事業例は1〜2個に絞る（列挙が多い場合は別スライドに分割）
- Y軸は「価値」のまま抽象で良い（実数値を書き込むグラフではなく概念図であるため）
