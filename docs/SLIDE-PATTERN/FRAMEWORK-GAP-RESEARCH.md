> 照合対象: 99種 SLIDE-PATTERN（`SLIDE-PATTERN-INDEX.md`）＋ V3.2 の8型（`5co-CI-kit/V3.2_FORMAT.md`）＋ `ci-charts.css`
> 出典: think-cell 公式マニュアル・BCG/Bain/McKinsey 公式・Umbrex・Analyst Academy・Deckary・Stratechi ほか（末尾）

> **実装ステータス（2026-07-11・v3.6）**: 本レポートの Tier 1 全8型＋Tier 2 全13型＋Tier 3 のうち8型＝
> **計29種を SLIDE-PATTERN として実装済み**（INDEX カテゴリ「🧠 フレームワーク・分析」参照・全128種3色QA合格）。
> 未実装の残り（サンキー・コストカーブ・プロフィットプール・サービスブループリント・エコシステムマップ・
> 四分位ベンチマーク・ダンベル/バンプ/箱ひげ・9区画キャンバス派生等）は必要時に追加。

## 結論（サマリー）

McKinsey・BCG・Bain が標準的に使うフレームワーク／チャート約 **120型** を調査し照合した結果、
現在の 99種＋8型は**レイアウト型（表紙・リスト・カード・基本グラフ）は厚いが、
コンサルの「分析を語る図」の中核が大きく欠けている**。

- **完全に欠落: 約30型**（ウォーターフォール・イシューツリー/ドライバーツリー・汎用2x2ポジショニング・ファネル図・ハーベイボール比較・ガント・散布/バブル・レーダー・ヒートマップ・メッコ・階層ピラミッド・同心円・バリューチェーン・ストラテジーハウス・スイムレーン・カスタマージャーニー等）
- **部分対応: 約10型**（risk-matrix-2x2 は「リスク専用」で汎用2x2に未対応、goal-kgi-kpi-dashboard は積層でありツリーでない、V3.2 `fnl` は2系統比較でファネル転換率図でない等）
- 特に**「ロジック・ツリー系」（イシューツリー／ドライバーツリー／ピラミッドストラクチャー）はゼロ**。
  これはコンサル流の「主張→根拠」「KPI分解」を1枚で見せる最重要ジャンルであり、最優先の補充候補。

## 1. 既存資産のうち「コンサル系フレームワーク図」と言えるもの

99種のうちフレームワーク図に該当するのは以下の約10種（他はレイアウト型）:

| 既存パターン | 対応するコンサル正典 |
|---|---|
| risk-matrix-2x2 | リスクマトリクス（影響度×発生確率）※リスク専用ラベル |
| pdca-cycle-diagram / cycle-diagram-with-labels | PDCA・循環図 |
| hub-spoke-diagram / polygon-hub-spoke | ハブ&スポーク（7S の簡易代替可） |
| org-chart-tree / team-org-with-photo | 組織図 |
| before-after-two-col / problem-solution | As-Is→To-Be・課題→解決 |
| goal-kgi-kpi-dashboard | 目標カスケード（積層型） |
| comparison-matrix-table / comparison-table-with-highlight | オプション比較表（記号セルなし） |
| milestone-timeline / staircase-roadmap 系 | タイムライン・成熟度段階図 |
| two-circle-bilateral-flow | 双方向関係図（Vennではない） |
| バー・円・ドーナツ・折れ線系 13種 | 基本チャート |

`ci-charts.css` は棒グラフ系のみ（増減セマンティクス `pos/neg` 実装済＝ウォーターフォール転用に好適）。

## 2. 欠落フレームワーク一覧（カテゴリ別・優先度付き）

優先度: ★★★=5coの週次CI・戦略資料で即使う ／ ★★=案件次第で頻出 ／ ★=ニッチ（必要時に追加）

### 2.1 ロジック・ツリー系（最大の欠落領域）

| 型 | 使用ファーム | 何を可視化するか | 既存対応 | 優先度 |
|---|---|---|---|---|
| イシューツリー / ロジックツリー | McKinsey 発・全ファーム | 問いをMECEに分解し検討の抜け漏れを防ぐ（左→右ツリー） | なし | ★★★ |
| ドライバーツリー / KPIツリー | McKinsey・BCG 常用 | 利益・KPIを四則演算で分解しレバーを特定（演算子付きツリー） | goal-kgi-kpi は積層で代替不可 | ★★★ |
| ピラミッドストラクチャー | McKinsey（Minto） | 結論を頂点に根拠を階層化（3層ピラミッド） | なし | ★★ |
| 仮説ツリー→ワークプラン | McKinsey・BCG | サブ仮説に分析・担当・期限を割当（ツリー＋右側表） | なし | ★★ |
| 決定木 | 全ファーム | 選択肢と結果の分岐・期待値 | なし | ★ |
| 特性要因図（フィッシュボーン） | オペ改善系 | 問題の原因をカテゴリ別に体系化 | なし | ★ |

### 2.6 図ではなく「文章構造」として扱うべきもの（COPY_GUIDE 側）

- **SCQA**（状況→複雑化→問い→答え）: エグゼクティブサマリーの構造。`COPY_GUIDE.md` の「問いへの答え」方式と同系。パターンではなく文言規範への追記候補。
- **So-What ラダー**: ファクト→示唆の昇華。同上。

## 3. 優先度付き提言

### Tier 1 — 最優先8型（週次CI・戦略資料で即使う／CI v2 3色で実装容易）

1. **ウォーターフォール（ブリッジ）** — `ci-charts.css` の pos（ティール）/neg（ブリック）機能色をそのまま流用可能。予実差異・利益分解に即効
2. **汎用2x2ポジショニング** — risk-matrix-2x2 の汎用化（軸ラベル・象限ラベル・バブル配置を差替可能に）。SWOT/Ansoff/インパクト×容易性/ステークホルダーを1型でカバー
3. **ドライバーツリー（KPIツリー）** — 数値はデータ由来のみの原則と好相性。売上・利益分解の定番
4. **イシューツリー（ロジックツリー）** — 論点整理・提案の構造化
5. **ファネル図** — 採用・営業・マーケの転換率。V3.2 `fnl`（2系統比較）と相互補完
6. **ハーベイボール比較表** — 3色制約でも ○◑●（ink 塗り分け円）で実装可能。ベンダー・施策比較
7. **100%積み上げ棒** — 構成比推移の作法標準
8. **ガント／フェーズ×ワークストリーム型ロードマップ** — 計画表 `pdstr` の視覚版

### Tier 2 — 次点13型（案件次第で頻出）

散布/バブル・ヒートマップ・レーダー・メッコ・階層ピラミッド・同心円（TAM/SAM/SOM）・ベン図・バリューチェーン・ストラテジーハウス・スリーホライズン（S字）・カスタマージャーニー・スイムレーン・3x3（9box）

### Tier 3 — ニッチ（必要になった時に追加）

トルネード・バタフライ・サンキー・コストカーブ・プロフィットプール・フィッシュボーン・氷山・決定木・9区画キャンバス・サービスブループリント・エコシステムマップ・四分位ベンチマーク・ダンベル/バンプ/箱ひげ・スロープ・CAGR矢印作法

### 実装時の注意（CI v2 制約との整合）

- **3色制約は障害にならない**: 濃淡（crystal-25/55・ink 階調）でヒートマップ・ハーベイボール・ファネルのグラデーションは表現可能。増減は既存の機能色（pos/neg）を使う
- **追加方法**: SLIDE-PATTERN 形式（`SLIDE-PATTERN-<name>/` に .md＋.html）で追加 → `SLIDE-PATTERN-INDEX.md` に登録すれば `framework-recommend` の発見枠に自動で乗る → `ci_pattern_adapter.py` で CI v2 変換
- **INDEX に「🧠 フレームワーク・分析」カテゴリ新設**を推奨（現在は図解・テーブル等に分散しており、レコメンダの発見加点が効きにくい）
