# SLIDE-PATTERN-phase-workstream-roadmap

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** phase-workstream-roadmap
**概要：** 列＝3フェーズ（期間ラベル付き）、行＝4ワークストリームのマトリクス型ガントチャート。セル内に施策バー（グレー階調・施策名内書き）がフェーズをまたいで伸び、ひし形のマイルストーンを要所に配置する。「いつ・どの領域で・何をするか」を1枚で示す実行計画の型。
**適したシーン：** 変革プログラム・中期計画の実行ロードマップ、プロジェクト全体計画のキックオフ提示、経営報告での進捗と今後の見通し説明

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| フェーズヘッダー | 期間の区切りと各フェーズの目的を示す | 名称6〜10文字＋期間ラベル |
| ワークストリームラベル（左端） | 施策の領域・チームを示す | 4〜7文字、4行が基本 |
| 施策バー | 施策の実施期間（フェーズまたぎ可）。名前は内書き | 各行2〜3本、施策名6〜14文字 |
| グレー階調 | 時系列（薄→濃）で進行段階を直感的に示す | — |
| マイルストーン（ひし形） | 意思決定・リリース等の要所 | 全体で2〜4個、ラベル4〜8文字 |
| 凡例 | バーとひし形の意味を補足 | 1行 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-phase-workstream-roadmap.md を参照して、
以下の計画をフェーズ×ワークストリーム型ロードマップにしてください。
横軸は12単位（1フェーズ=4単位）とし、バーの開始・終了は単位で指定します。

【フェーズ】
Phase 1 基盤構築（2026年4月〜9月）/ Phase 2 展開（2026年10月〜2027年3月）
/ Phase 3 定着（2027年4月〜9月）

【業務プロセス】
- 業務棚卸し・新プロセス設計（単位1〜5）
- 新プロセス全社展開（単位6〜10）
- 定着モニタリング（単位11〜12）
- マイルストーン: 展開判定（Phase1末）

【システム】
- 要件定義・開発（単位1〜6）/ 段階リリース（単位7〜10）/ 保守運用へ移行（単位11〜12）
- マイルストーン: 全社リリース（Phase2末）

【人材・組織】
- 推進体制立ち上げ（単位1〜3）/ 階層別研修（単位4〜9）/ 社内認定制度の運用（単位10〜12）

【ガバナンス】
- KPI設計（単位1〜2）/ 四半期ごとの効果測定（単位3〜10）/ 定着レビュー（単位11〜12）
- マイルストーン: 効果検証完了（Phase3末）

【スライドタイトル】
業務改革プログラム 全体ロードマップ（18ヶ月）
```

### 注意点
- ワークストリームは4行が基本（5行まで許容、6行以上は2枚に分割）
- 施策バーは1行あたり2〜3本まで。バー内テキストは14文字以内（はみ出すなら短縮）
- 12単位グリッドを使うとバーの開始・終了をフェーズ途中に置ける（フェーズまたぎ表現が可能）
- マイルストーンは「意思決定・リリース・完了判定」のみに絞る（多用すると効果が薄れる）
- グレー階調は「時系列で薄→濃」に統一する（濃淡に別の意味を混ぜない）
- 期間ラベルは実際の年月に置き換える。半期・四半期・月次いずれでも12単位に割り付ければよい
