## Overview
**パターン名：** layered-pyramid-hierarchy
**概要：** 水平にスライスした三角形（4層程度）で階層構造を示すピラミッド図。各層にラベルを置き、右側に各層の説明テキストを引き出し線で並べる。上位=抽象・下位=具体（基盤）の積み上げ関係を1枚で示す。
**適したシーン：** 理念→戦略→施策→日常業務の階層整理、価値階層・ブランド構造、Target Operating Model、スキル・組織能力の積み上げ構造

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| ピラミッド層（4層） | 階層の上下関係と積み上げ構造を示す | 3〜5層 |
| 層ラベル | 各層の名称（図形内に表示） | 2〜6文字 |
| 層の濃淡 | 上位ほど濃く、階層の序列を視覚化 | テキストなし |
| 引き出し線 | 層と右側説明の対応を示す | 破線1px |
| 層の説明テキスト | 各層の具体的内容・例を補足 | 名称＋本文40〜60文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-layered-pyramid-hierarchy.md を参照して、
以下の4階層をピラミッド図に整理したスライドを作成してください。

【階層（上から順に）】
1. 理念: 「地域の中小企業のDXを支える」— 全判断のよりどころ
2. 戦略: 3年で受託中心からクラウド中心へ事業転換
3. 施策: SaaS開発投資・パートナー販路開拓・CS組織新設
4. 日常業務: 週次の解約予兆レビュー・問い合わせSLA計測

【スライドタイトル】
理念から日常業務まで — 全階層が一本につながっているか
```

### 注意点
- 層は3〜5層が適切（6層以上は各層が薄くなり文字が入らないため分割する）
- 頂点の第1層は幅が狭いので、層ラベルは2〜4文字に抑える（長い名称は右側の説明に書く）
- 上=抽象・目的、下=具体・基盤という向きを崩さない（逆向きにする場合は逆ピラミッドとして意図を明示する）
- 各層の説明は引き出し線の高さと必ず揃える（層と説明の対応がずれると誤読を生む）
- 層の面積は重要度や量を意味しない。量の比較を見せたい場合は棒グラフ等を使う
- 階層でなく絞り込み（全体→ターゲット）を示したい場合はファネル図や concentric-circles-market を使う
