このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** tornado-sensitivity-chart
**概要：** 中央の縦基準線から左（下振れ・濃グレー）と右（上振れ・薄グレー）に横棒を伸ばし、影響度の大きい変数から順に上から並べるトルネードチャート。棒端に±の影響額ラベル、各行左端に変数名（変動幅つき）を置き、「どの変数が結果を最も揺らすか」を一目で示す。
**適したシーン：** 感度分析（利益・NPV・コストへの影響要因）、事業計画のリスクドライバー特定、投資判断の前提検証、シナリオ分析の要約

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 中央の縦基準線 | 基準値（乖離ゼロ）の位置 | テキストなし（下に「0」） |
| 変数名（左端列） | 感度を測った変数と変動幅 | 「販売数量（±10%）」形式、10文字前後 |
| 左向きの棒（#666666） | 下振れシナリオでの影響幅 | 5〜7行 |
| 右向きの棒（#CCCCCC） | 上振れシナリオでの影響幅 | 5〜7行 |
| ±値ラベル（棒端） | 影響額を数値で明示 | 「−42」「+38」等、符号必須 |
| 基準値の注記 | 何を基準にした感度か | 1行30〜50文字 |
| ゾーン見出し | 左＝減少・右＝増加の向きを明示 | 各10〜15文字 |
| 単位ラベル | 影響額の単位 | 「営業利益への影響額（億円）」等 |
| 図の読み方 | 「上ほど影響大」の読解ガイド | 1文40〜60文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-tornado-sensitivity-chart.md を参照して、
以下の感度分析をトルネードチャートで示すスライドを作成してください。

【基準値】2026年度計画 営業利益 250億円
【感度分析結果（営業利益への影響額・億円）】
- 販売数量 ±10%: −42 / +42
- 販売単価 ±5%: −35 / +38
- 原材料費 ±8%: −28 / +25
- 為替レート ±5円/ドル: −18 / +20
- 人件費 ±3%: −12 / +10
- 物流費 ±5%: −8 / +7

【スライドタイトル】
利益の変動要因は販売数量と単価に集中 — 上位2変数で影響の6割

【単位】億円
```

### 注意点
- 行は必ず影響度（左右の影響幅の大きい方）の降順で上から並べる。これが「トルネード（漏斗形）」の形を作る
- 行数は5〜7行が適切。影響の小さい変数は「その他」にまとめるか省略する
- バー幅は「影響額 ÷ 最大影響額 × 90%」で計算する（最大の変数でもゾーン幅の90%に収め、値ラベルの余白を残す）
- 各変数の変動幅（±10%等）を変数名に必ず併記する。変動幅の前提が揃っていないと影響額を比較できないため
- 値ラベルには符号（+/−）を必ず付ける。左＝濃グレー・右＝薄グレーの濃淡ルールを崩さない
- 左右非対称（−35 / +38 等）はそのまま描く。対称に丸めると分析の情報が失われる
