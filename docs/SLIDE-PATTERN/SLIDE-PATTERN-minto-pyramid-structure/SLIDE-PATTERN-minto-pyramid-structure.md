# SLIDE-PATTERN-minto-pyramid-structure

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** minto-pyramid-structure
**概要：** 頂点の結論ボックス（濃グレー・大）→中段のキーライン根拠3つ→下段のデータ・ファクト6個、の3層を接続線で結ぶピラミッド型ツリーのスライド。「主張→根拠→事実」の論証構造を1枚で示す。
**適したシーン：** エグゼクティブサマリー設計、提案・稟議の論証構造の提示、報告書の骨子共有、結論先出しのプレゼン冒頭

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 結論ボックス（頂点・濃グレー） | 読者の問いへの答えを1文で言い切る | 15〜25文字の主張1文 |
| キーラインボックス（中段） | 結論を支える根拠。3つでMECEに | 3個、各20〜28文字 |
| ファクトボックス（下段） | 各根拠を支えるデータ・事実 | 6個（根拠1つに2個）、各20〜28文字 |
| 接続線（SVG） | 「支える／支えられる」関係を示す | — |
| 層タグ（結論／根拠／ファクト） | 各層の役割を明示 | 各2〜5文字 |
| 脚注（図の読み方） | ピラミッドの検証方法を補足 | 1文 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-minto-pyramid-structure.md を参照して、
以下の論証構造をピラミッドストラクチャーで示すスライドを作成してください。

【結論】
社内問い合わせ対応にAIチャットボットを導入すべきである

【根拠1】対応コストが大きい
- ファクト: 月間問い合わせ2,400件、対応工数は月380時間
- ファクト: 対応人件費は年間換算で約2,300万円

【根拠2】定型質問が大半で自動化に向く
- ファクト: 問い合わせの72%が上位20問のFAQで解決可能
- ファクト: 他社事例では同種問い合わせの65%を自動化

【根拠3】導入・運用の障壁が低い
- ファクト: 既存の社内ポータルにAPI連携で組み込み可能
- ファクト: 初期費用300万円、6カ月で回収見込み

【スライドタイトル】
AIチャットボット導入を提案する3つの理由
```

### 注意点
- 結論は必ず「読者の問いへの答え」を1文で言い切る（「〜の検討状況」のような分類名は不可）
- キーラインは3つが基本（2つは弱く、4つ以上は覚えられない）。互いにMECEにする
- ファクトには必ず数値・出典・事実を入れる（意見や形容詞だけの「根拠のような文」を置かない）
- 上下の論理を必ず検証する: 下から上へ「だから何？（So What?）」、上から下へ「なぜ？（Why So?）」が通ること
- 接続線のSVG座標は固定幅（864px）前提で計算されている。ボックス幅を変える場合は座標を再計算する
- ファクトが根拠1つにつき3個以上ある場合は代表2個に絞り、残りは補足資料に回す
