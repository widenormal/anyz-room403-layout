このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** mekko-market-map
**概要：** 横幅＝セグメント市場規模に比例した可変幅の列を並べ、各列内を100%積み上げ（プレイヤー別シェア）で分割するメッコ（Marimekko）チャート。列上部に市場規模ラベル、セル内にシェア%を表示し、「どの市場が大きく・誰が強いか」を面積で一望させる。
**適したシーン：** 市場構造の俯瞰、参入市場の優先度検討、競合ポジション分析、事業ポートフォリオと市場規模の同時説明

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 可変幅の列（3〜5列） | 市場セグメント。横幅が市場規模に比例 | セグメント名4〜8文字 |
| 列上部の市場規模ラベル | 各セグメントの規模と全体比 | 「1,200億円（43%）」形式 |
| セル（プレイヤー別シェア） | 各セグメント内の競争構造。濃淡は全列で統一 | 各列3〜4セルまで |
| セル内シェア%ラベル | 各プレイヤーのシェアを明示 | 整数% |
| Y軸目盛（0〜100%） | 列内が100%積み上げであることを示す | 25%刻み固定 |
| 全体規模の注記 | 市場合計と基準年度を示す | 1行30〜50文字 |
| 凡例 | プレイヤー名と濃淡の対応 | 3〜4項目 |
| 図の読み方 | 「横幅＝規模・縦＝シェア・面積＝売上」の明示 | 1文40〜60文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-mekko-market-map.md を参照して、
以下の市場構造をメッコチャートで示すスライドを作成してください。

【市場全体】国内ITサービス市場 2,800億円（2025年度）
【クラウド基盤 1,200億円】自社 38% / 競合A社 27% / 競合B社 20% / その他 15%
【業務SaaS 800億円】自社 22% / 競合A社 41% / 競合B社 22% / その他 15%
【セキュリティ 500億円】自社 15% / 競合A社 30% / 競合B社 35% / その他 20%
【運用サービス 300億円】自社 45% / 競合A社 25% / 競合B社 18% / その他 12%

【スライドタイトル】
最大市場のクラウド基盤で首位、SaaSはA社が先行

【凡例】自社 / 競合A社 / 競合B社 / その他
```

### 注意点
- 列の可変幅は CSS flex の flex-grow に市場規模の数値をそのまま指定して表現する（目分量の%指定はしない）
- 各列のシェア合計は必ず100%になるよう検算する
- セグメント（列）は3〜5列、プレイヤー（セル）は3〜4段が上限。細かいプレイヤーは「その他」に集約
- プレイヤーの濃淡と積み順は全列で統一する（主役プレイヤーを最下段・最濃に）
- 最小の列は幅が狭くなるため、セグメント名を短縮し（例:「運用サービス」→「運用」）、規模ラベルの全体比%は省略してよい
- 市場合計・基準年度・出典は必ずヘッダ注記に明示する（数値の出所が問われる図のため）
