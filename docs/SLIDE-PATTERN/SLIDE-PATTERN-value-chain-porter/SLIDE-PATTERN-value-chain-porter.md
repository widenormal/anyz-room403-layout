# SLIDE-PATTERN-value-chain-porter

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** value-chain-porter
**概要：** Porter型バリューチェーン。上段に支援活動4層（全般管理・人事労務管理・技術開発・調達）を横帯で積層し、下段に主活動5つ（購買物流→製造→出荷物流→販売・マーケティング→サービス）を右向き矢羽（chevron）で連結、右端に「マージン」の三角を置く。各ブロックに活動名と強み・弱みの短評を記載する。
**適したシーン：** 価値の源泉の特定、コスト構造分析、競争優位の棚卸し、業務プロセス改善の対象選定、DX投資対象の議論

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 支援活動の横帯（4層） | 全活動を横断して支える機能 | 活動名5〜12文字＋短評12文字以内 |
| 主活動の矢羽（5個） | 価値を生む本流プロセス（左→右） | 活動名3〜8文字＋短評10文字以内 |
| マージン三角（右端） | 全活動の結果として残る利益 | 「マージン」固定または「利益」 |
| 強み・弱み短評 | 各活動の競争力評価 | 「強み：」「弱み：」＋8〜10文字 |
| セクションラベル | 支援活動／主活動の区分表示 | 3〜4文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-value-chain-porter.md を参照して、
以下のバリューチェーン分析をスライドにしてください。

【支援活動】
- 全般管理：強み：意思決定が速い
- 人事・労務管理：弱み：採用力が不足
- 技術開発：強み：特許3件保有
- 調達：弱み：仕入先が1社集中

【主活動（左から順に）】
- 購買物流：弱み：在庫過多
- 製造：強み：不良率0.1%
- 出荷物流：強み：翌日納品
- 販売・マーケ：弱み：新規開拓弱い
- サービス：強み：継続率95%

【スライドタイトル】
バリューチェーン分析：価値の源泉はどこか
```

### 注意点
- 主活動は5つが標準（業種に合わせて4〜6個まで調整可。それ以上は文字が潰れる）
- 短評は「強み：」「弱み：」の接頭辞で統一すると濃淡だけに頼らず判別できる
- 強い活動のブロックを濃いグレー、弱い活動を薄いグレーにして視覚的に強弱をつけてもよい
- マージン三角は削らない（「全活動の差分が利益」というPorter型の意味が失われる）
- 業種がサービス業の場合は活動名を置換する（例：購買物流→情報収集、製造→サービス提供）
