# SLIDE-PATTERN-customer-journey-map

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** customer-journey-map
**概要：** 横軸に顧客の5ステージ（認知→検討→購入→利用→推奨）、縦軸に「顧客の行動」「タッチポイント」「感情曲線」「ペインポイント」「打ち手」を並べたグリッドで、顧客体験を段階別に俯瞰するスライド。感情曲線はSVG折れ線で山谷を表現し、ペインポイントは濃グレーバッジで強調する。
**適したシーン：** 顧客体験（CX）の段階別分析、マーケティング施策の全体設計、CS/サポート改善の議論、サービス改善の優先順位づけ

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| ステージヘッダー | 顧客の時系列段階を示す（左→右） | 各2〜4文字、5ステージ固定が基本 |
| 顧客の行動 | 各段階で顧客が実際にすること | 各セル15〜25文字 |
| タッチポイント | 顧客との接点チャネル | 各セル2〜3項目、「／」区切り |
| 感情曲線（SVG折れ線） | 感情の山谷を可視化。谷＝改善機会 | テキストなし（点5個＋折れ線） |
| ペインポイントバッジ | 各段階の不満・障壁（濃グレーで強調） | 各セル1個、8〜14文字 |
| 打ち手 | ペインに対応する施策 | 各セル10〜16文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-customer-journey-map.md を参照して、
以下の内容でカスタマージャーニーマップのスライドを作成してください。

【ステージ】認知 / 検討 / 購入 / 利用 / 推奨

【認知】行動: 経費精算の負担を認識しWeb検索 ／ TP: 検索広告・比較サイト
／ ペイン: 情報が多く比べにくい ／ 打ち手: 課題別比較ガイド
【検討】行動: 3社比較・無料トライアル ／ TP: 製品サイト・営業デモ
／ ペイン: 比較の軸が定まらない ／ 打ち手: 選定チェックリスト提供
【購入】行動: 稟議を通し年間契約 ／ TP: 見積書・営業担当
／ ペイン: 稟議資料の作成が負担 ／ 打ち手: 稟議用テンプレート同梱
【利用】行動: 初期設定と月次利用 ／ TP: 管理画面・サポート窓口
／ ペイン: 初期設定でつまずく ／ 打ち手: 初期設定の伴走サポート
【推奨】行動: 他部門・取引先に紹介 ／ TP: 導入事例取材・紹介プログラム
／ ペイン: 紹介の動機が弱い ／ 打ち手: 紹介インセンティブ制度

【感情曲線】認知=中 / 検討=谷 / 購入=山 / 利用=谷 / 推奨=最高

【スライドタイトル】
経費精算SaaSのカスタマージャーニーと改善打ち手
```

### 注意点
- ステージは5個が基本。BtoBなら「認知→情報収集→比較検討→導入→活用→更新」など6個まで許容（列幅に注意）
- 感情曲線の「谷」とペインポイントの行を縦に揃えると、改善機会が一目で伝わる
- 各セルのテキストは2行以内に収める（3行以上になるなら言葉を削る）
- 行は4〜5行が上限。「KPI」行を足す場合は「タッチポイント」行と入れ替える
- ペインバッジは各セル1個に絞る（複数あるなら最重要のみ）
