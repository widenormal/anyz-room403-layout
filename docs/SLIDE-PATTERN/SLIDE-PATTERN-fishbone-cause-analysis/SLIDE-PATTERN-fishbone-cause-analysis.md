# SLIDE-PATTERN-fishbone-cause-analysis

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** fishbone-cause-analysis
**概要：** 右端の問題ボックス（魚頭）に向かう水平の背骨線へ、上下から斜めの大骨4本（ヒト・プロセス・システム・環境等のカテゴリ）が刺さり、各大骨に原因テキストの小骨2〜3本を付ける特性要因図（フィッシュボーン／石川ダイアグラム）のスライド。全体をインラインSVGで描画する。
**適したシーン：** 問題の原因の体系的な洗い出し、品質不良・障害・遅延の要因分析、改善活動（QC）の現状整理、対策検討前の原因マップ共有

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 問題ボックス（魚頭・濃グレー） | 分析対象の問題を定量表現で示す | 12〜20文字（数値を含める） |
| 背骨（水平線・矢印） | すべての原因が問題へ向かう構造を示す | — |
| 大骨（斜め線）＋カテゴリラベル | 原因の分類軸（ヒト・プロセス・システム・環境等） | 4本、各2〜5文字 |
| 小骨（水平線＋原因テキスト） | カテゴリ内の具体的な原因 | 各大骨2〜3本、各8〜12文字 |
| 脚注（図の読み方） | 図の構造の読み方を補足 | 1文 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-fishbone-cause-analysis.md を参照して、
以下の問題の原因を特性要因図で整理したスライドを作成してください。

【問題（魚頭）】
Webサイトの離脱率が高い（直帰率68%）

【ヒト】
- 担当者のSEO知識が不足
- 更新が特定個人に依存

【プロセス】
- 公開前のレビューが形骸化
- 改善サイクルが年1回のみ

【システム】
- ページ表示に4秒かかる
- スマホ表示が崩れる

【環境】
- 競合が検索上位を独占
- 広告流入の質が低い

【スライドタイトル】
直帰率68%の原因はどこにあるか
```

### 注意点
- 問題（魚頭）は必ず定量表現にする（「遅い（平均14日）」のように数値を添える）
- カテゴリは4本が基本。定番は「ヒト・プロセス・システム・環境」や製造業の4M（人・機械・材料・方法）で、内容に合わせて変更してよい
- 小骨は各大骨2〜3本まで（4本以上は文字が重なる。多い場合は影響の大きい原因に絞る）
- 原因は「〜が〜する／している」の事実文で書く（「教育」だけのような名詞の羅列にしない）
- 原因の列挙で終わらせず、次のスライドで対策（どの骨から手を打つか）につなげる
- 座標は固定SVG（864×450）前提。カテゴリ数や小骨数を変える場合は重なりがないよう座標を再計算する
