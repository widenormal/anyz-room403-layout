# SLIDE-PATTERN-iceberg-visible-hidden

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** iceberg-visible-hidden
**概要：** 氷山のメタファーで「見えている事象」と「水面下の原因」を対比するスライド。中央の水面線（横破線＋薄グレー帯）の上に小さな三角（氷山の一角＝事象）、下に大きな氷山本体（「構造」「メンタルモデル」の2層）を描き、右側に各層の説明パネルを置く。深い層ほど働きかけの効果（レバレッジ）が大きいことを矢印で示す。
**適したシーン：** 問題の根本原因分析（システム思考）、組織課題・風土改革の議論、「対症療法ではなく構造に手を打つ」提案の導入、経営層への課題構造の説明

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 水面線 | 「見える／見えない」の境界を示す | ラベル1行 |
| 氷山の一角（三角） | 表面化している事象の象徴 | 見出し「見えている事象」固定 |
| 事象チップ | 観測できる具体的な出来事 | 2個、各8〜12文字 |
| 氷山本体・構造層 | 事象を生む制度・プロセス・力学 | 原因2個、各10〜14文字 |
| 氷山本体・メンタルモデル層 | 構造を支える暗黙の前提（最深部・白文字） | 原因1〜2個、各10〜16文字 |
| レバレッジ矢印 | 深い層ほど効果が大きいことを示す | 1行 |
| 説明パネル（右側3枚） | 各層の定義と「なぜ深掘るか」の論理 | 各パネル30〜45文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-iceberg-visible-hidden.md を参照して、
以下の内容で氷山図のスライドを作成してください。

【見えている事象（水面上・2個）】
- 若手の離職が増加
- 営業目標の未達が続く

【構造（水面下・上層）】
- 評価制度が短期成果に偏重
- 部門間で顧客情報が分断

【メンタルモデル（水面下・最深部）】
- 「失敗は個人の責任」という暗黙の前提

【右側パネルの説明】
- 事象: 観測できる出来事。ここだけの対処は対症療法で再発する
- 構造: 事象を繰り返し生む制度・プロセス。仕組みを変えると事象が変わる
- メンタルモデル: 構造を支える暗黙の前提。ここへの働きかけが根本解決

【スライドタイトル】
離職と未達は「氷山の一角」── 水面下の構造に手を打つ
```

### 注意点
- 事象は2個、構造の原因は2個、メンタルモデルは1〜2個に絞る（氷山内のテキストは短く）
- 下層ほど濃いグレーにする（可視性が低い＝濃い、のメタファーを崩さない）
- 最深層は白文字（#FFFFFF）でコントラストを確保する
- 層の名前は文脈に合わせて変更可（例：「行動パターン」「組織風土」「前提・信念」の3層）
- 右パネルの「▼ なぜ〜」の接続文が論理の橋渡し。省略しない
- このパターンは「だから構造に手を打つ」という次スライドの提案とセットで使うと効果的
