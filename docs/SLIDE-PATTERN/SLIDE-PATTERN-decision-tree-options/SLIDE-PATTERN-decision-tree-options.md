# SLIDE-PATTERN-decision-tree-options

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** decision-tree-options
**概要：** 左端の判断ノード（四角）から2分岐し、各枝の先の確率ノード（円）を経て結果ボックス4つ（期待値ラベル付き）へ至る、左→右の決定木スライド。枝上に条件ラベル（採用する/しない、成功60%/失敗40% 等）を置き、期待値が最大の選択肢を濃色バッジで強調する。
**適したシーン：** 選択肢と期待値の整理、投資判断、Go/No-Go判断、不確実性を含む意思決定の説明

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 判断ノード（四角・濃グレー） | 意思決定者が選べる分岐点 | 「判断：〜するか」10〜15文字 |
| 確率ノード（円） | 選べない不確実性の分岐点 | 「確率」2文字（形で区別） |
| 枝ラベル（条件） | 各選択肢の内容とコスト | 各8〜14文字 |
| 確率ラベル | 各結果の発生確率 | 「成功 60%」など5〜8文字 |
| 結果ボックス | 結末・金額・期待値への寄与 | 4個、各3行以内 |
| 期待値バッジ | 枝ごとの期待値。最大の枝を濃色で強調 | 各10文字前後 |
| 凡例 | ノード形状と濃色の意味 | 3項目 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-decision-tree-options.md を参照して、
以下の意思決定を決定木で整理したスライドを作成してください。

【判断】
基幹システムを今期リプレイスするか

【選択肢1】リプレイスする（投資 1.5億円）
- 計画通り完了 70%：運用コスト削減 ＋0.6億円／年
- 遅延・追加開発 30%：追加コスト −0.5億円

【選択肢2】リプレイスしない（延命保守）
- 安定稼働 80%：保守費 −0.2億円／年
- 大規模障害 20%：損失 −2.0億円

【スライドタイトル】
リプレイス判断：期待値で見るとどちらが得か
```

### 注意点
- 期待値は必ず検算する（期待値 ＝ Σ 結果金額 × 確率。各枝の確率の合計は100%にする）
- 数値はデータ由来のみ。確率の根拠（過去実績・専門家見積り等）を脚注か発表原稿で示せるようにする
- 判断ノード（四角）＝選べる分岐、確率ノード（円）＝選べない分岐、の形の使い分けを崩さない
- 分岐は2択×結果4つが読みやすい上限。3択以上や3段以上の分岐は枝を刈り込むか2枚に分ける
- 濃色の強調は「期待値最大の枝」1つだけに使う
- 金額だけで決められない要素（ブランド毀損等）がある場合は結果ボックス内に定性注記を添える
- 固定座標キャンバス（864×450）前提。ノード数を変える場合は座標を再計算する
