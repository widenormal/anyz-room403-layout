# SLIDE-PATTERN-issue-logic-tree

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** issue-logic-tree
**概要：** 左端の問い（イシュー）を、中央の論点3つ→右のサブ論点6〜7個へと横型ツリーで分解するスライド。L字罫線の接続線でMECE（モレなくダブりなく）な分解構造を可視化する。
**適したシーン：** 論点の構造化、検討の抜け漏れ防止、プロジェクト初期の課題分解、問題解決アプローチの全体像共有

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 問いボックス（左端・濃グレー） | ツリー全体の起点となるイシューを1つ示す | 20〜30文字の疑問文1つ |
| 論点ボックス（第1階層） | 問いをMECEに分解した大論点 | 3個、各8〜12文字 |
| サブ論点ボックス（第2階層） | 各論点をさらに具体化した検討単位 | 合計6〜7個、各10〜16文字 |
| L字接続線 | 親子関係（分解の構造）を示す | — |
| カラム見出し | 各階層の意味を示す | 各5〜10文字 |
| 脚注（図の読み方） | MECE分解であることを補足 | 1文 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-issue-logic-tree.md を参照して、
以下の問いをイシューツリーに分解したスライドを作成してください。

【問い】
解約率を1年で半減させるには何をすべきか？

【論点1】オンボーディングを改善できるか
- 初期設定の離脱を減らせるか
- 活用トレーニングを提供できるか
- 導入初月の成功体験を作れるか

【論点2】利用定着を高められるか
- 利用頻度の低い顧客を検知できるか
- 機能の利用範囲を広げられるか

【論点3】解約時の引き留めを強化できるか
- 解約理由を事前に把握できるか
- 代替プランを提示できるか

【スライドタイトル】
解約率半減に向けた論点の全体像
```

### 注意点
- 問いは必ず疑問文にする（「〜するには？」「〜できるか？」）。体言止めの分類名にしない
- 第1階層は3個・第2階層は合計6〜7個が上限（それ以上は文字が小さくなり読めない）
- 同一階層はMECEにする（重複・欠落があると「分解の質」を疑われる）
- サブ論点の数が論点ごとに異なる場合は、グループの高さ（flex比率）をサブ論点数に合わせる
- 3階層以上必要な場合はこのパターンを2枚に分ける（1枚に詰め込まない）
