# SLIDE-PATTERN-stacked-bar-100pct

このファイルはスライドのコンテンツエリア（タイトル行より下の領域）のレイアウトパターン定義書です。SLIDE.mdと組み合わせてAIツールに渡すことで、このパターンのスライドを生成できます。タイトルエリア・ページ番号・装飾はSLIDE.mdの `Slide Frame` セクションで定義されるため、このファイルには含みません。

## Overview
**パターン名：** stacked-bar-100pct
**概要：** 高さを100%に揃えた積み上げ棒を年度別（または拠点別・製品別）に3〜4本並べ、各棒を3〜4セグメント（グレー階調）に分割して構成比の推移を示すスライド。セグメント内に%ラベル、右側に凡例を置く。
**適したシーン：** 売上構成比の推移比較、事業ポートフォリオの変化、コスト構造の年度比較、顧客セグメント比率の変化

## Elements（各要素の役割）

| 要素 | 役割 | 推奨テキスト量 |
|------|------|--------------|
| 等高の棒（3〜4本） | 比較する期間・対象（年度等） | 棒3〜4本まで |
| セグメント（グレー階調） | 構成要素。基準セグメントを最下段・最濃にする | 各棒3〜4分割まで |
| %ラベル | 各セグメントの構成比を明示 | 「62%」等、整数% |
| Y軸目盛（0〜100%） | 100%基準であることを示す | 25%刻み固定 |
| X軸カテゴリラベル | 各棒の対象（年度名等） | 4〜8文字 |
| 凡例 | セグメント名と濃淡の対応 | 3〜4項目 |
| 図の読み方 | 「高さは同じ・割合を見る」ことの明示 | 1文40〜60文字 |

## Usage Guide（AIへの使い方）

### プロンプト例

```
SLIDE.md と SLIDE-PATTERN-stacked-bar-100pct.md を参照して、
以下の売上構成比の推移を100%積み上げ棒で示すスライドを作成してください。

【2022年度】国内事業 62% / 海外事業 24% / 新規事業 8% / その他 6%
【2023年度】国内事業 55% / 海外事業 28% / 新規事業 11% / その他 6%
【2024年度】国内事業 48% / 海外事業 31% / 新規事業 15% / その他 6%
【2025年度】国内事業 41% / 海外事業 33% / 新規事業 20% / その他 6%

【スライドタイトル】
新規事業の構成比は3年で8%から20%へ拡大

【単位】売上構成比（%）
```

### 注意点
- 各棒のセグメント合計は必ず100%になるよう検算する（端数は最大セグメントで調整）
- セグメントは3〜4分割が上限（細かい要素は「その他」に集約）
- セグメントの積み順と濃淡は全棒で統一する（最重要セグメントを最下段・最濃に）
- 5%未満の小セグメントは内側ラベルが入らないことがある。その場合はラベルを外側に引き出すか「その他」へ集約する
- 構成比の変化と絶対額の変化は別物。絶対額の増減も伝えたい場合は棒上部に総額ラベルを追加するか、別パターン（棒グラフ）と併用する
